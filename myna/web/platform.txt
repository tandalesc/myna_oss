# launcher, the device models its profile attaches, the AT modem stand-in with its cell network, the flash state and the
# compiled core's Python side. One path a line, from the repository root.
#   myna/web/serve.py           puts these files (and the BOOT_ELF device folders) into the page's archive, phone_src.json
#   tools/export_release.py     copies them into Myna's release
#   myna/firmware/test/stock_free.py   fails when a Myna run imports a file of the repository that is not listed here
# Found with an import tracer on myna/firmware/test/sim_telephony.py (both networks, the compiled core), plus dbcore_wasm.py,
# the core's binding for the browser. Nothing of the stock firmware's stand-ins, profiles or key tables is in the list.
